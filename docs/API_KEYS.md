## Generated by us (no signup)
- `JWT_PRIVATE_KEY` / `JWT_PUBLIC_KEY` - RS256 pair. Auto-generated per run in demo; **set fixed keys before prod** (otherwise logins reset on restart).
- `KYC_SIGNING_SECRET` - long random string. The built-in default is public in the repo; **override it**.
- `RABBIT_*` - only if you run RabbitMQ; demo skips it.

1. **Gemini** (2 min) -> 2. **Razorpay test** (5 min, needs account) -> 3. **Cloudinary** (3 min) -> 4. **Google Maps** (billing card) -> rest when each feature is built.

## Code reality check (today)

- Gemini model `gemini-1.5-flash` in `application.yml` is old; check the current model ID in Google AI Studio and update `GEMINI_MODEL`.
