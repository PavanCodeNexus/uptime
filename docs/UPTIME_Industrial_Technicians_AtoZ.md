## 1. Technician Level Hierarchy

```
LEVEL 6: Plant Manager / Chief Engineer
          → Manages entire plant maintenance
          → 15+ years experience
          → Degree/Diploma in Engineering

LEVEL 5: Maintenance Manager / Sr. Engineer
          → Manages maintenance team
          → 10+ years experience
          → Diploma/BE + ITI background

LEVEL 4: Maintenance Engineer / Supervisor
          → Leads repair team
          → 5–10 years experience
          → Diploma in Engineering

LEVEL 3: Senior Technician / Foreman
          → Handles complex repairs independently
          → 3–5 years experience
          → ITI + experience

LEVEL 2: Technician / Mechanic
          → Handles standard repairs
          → 1–3 years experience
          → ITI certified

LEVEL 1: Junior Technician / Helper
          → Assists senior techs
          → 0–1 year experience
          → ITI fresher / apprentice

LEVEL 0: Apprentice / Trainee
          → Learning under senior
          → ITI student / fresh pass
          → Not eligible for UPTIME solo jobs
```

## 3. By Industry Type

### 🏗️ Small Workshop / Job Shop (1–10 workers)

```
Technicians needed:
  → Fitter (general purpose)
  → Welder
  → Electrician (basic)
  → Lathe operator
  → Grinder

Typical machine repairs:
  Lathe, milling machine, drill press,
  grinding machine, welding machines

Avg repair cost: ₹500–₹5,000 per job
UPTIME urgency: Usually MEDIUM
```

### 🏭 Small MSME Factory (10–50 workers)

```
Technicians needed:
  → Electrical Maintenance Technician
  → Mechanical Fitter
  → Pump Mechanic
  → Compressor Technician
  → Motor Repair Technician

Typical repairs:
  Motors, pumps, compressors,
  electrical panels, conveyor belts

Avg repair cost: ₹2,000–₹20,000
UPTIME urgency: HIGH (production depends on it)
```

### 🏭 Medium Industry (50–500 workers)

```
Technicians needed:
  → PLC Technician
  → Hydraulic Mechanic
  → HVAC Technician
  → CNC Machine Technician
  → Instrumentation Technician
  → Electrical Engineer
  → Mechanical Engineer

Typical repairs:
  CNC machines, hydraulic presses,
  industrial HVAC, automation faults,
  instrumentation calibration

Avg repair cost: ₹5,000–₹1,00,000
UPTIME urgency: HIGH / CRITICAL
```

### 🏭 Large Scale Industry (500–5000 workers)

```
Technicians needed:
  → All of the above +
  → Turbine Technician
  → Robotic Technician
  → Switchgear Technician
  → NDT Technician
  → Vibration Analyst
  → Predictive Maintenance Specialist

Typical repairs:
  Turbines, large transformers, HT switchgear,
  industrial robots, large compressors

Avg repair cost: ₹10,000–₹10,00,000
UPTIME urgency: CRITICAL (huge downtime cost)
```

### 🏭 Heavy Industry (Steel, Cement, Power Plant)
